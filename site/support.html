Help and feedback

Report an issue or ask a question through the project issue tracker. Avoid including photos, private folder names, credentials or other sensitive information in a public issue.

Local save failed?

Reselect the original base folder, restore free space/provider access, then retry local saves in Settings. Export retained staging before uninstalling if the original destination cannot be restored.

PC unavailable?

Local capture continues. Check that the receiver is running on the same LAN and that its printed TCP port is reachable. Use Retry uploads now after resolving access or storage errors.
