Folders first

Nested paths, searchable folders and exact Unicode names. Every new session starts with your destination choice.

Local by default

Capture without an account, PC or internet connection. Saved photos remain in the folder you chose.

Your PC, optionally

Pair the open-source Linux receiver for certificate-verified HTTPS transfers over your LAN.

Start the receiver

With Deno and OpenSSL installed, run deno task start from the receiver directory. It selects a private LAN address and displays the first-use pairing QR automatically.

Folder Camera is GPL-3.0-or-later open-source software. No advertising, analytics or developer-operated photo server.
